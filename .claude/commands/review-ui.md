지정된 페이지 또는 컴포넌트의 UI/UX를 상세히 검토합니다.

## 검토 대상
파일 경로: $1

## 검토 항목
- **레이아웃**: 여백, 정렬, 계층 구조
- **반응형**: 모바일, 태블릿, 데스크톱 화면 크기 적응
- **접근성**: 컬러 대비, ARIA 라벨, 키보드 네비게이션
- **다크 모드**: 색상 재정의, 충분한 대비도
- **성능**: 이미지 최적화, 렌더링 효율성
- **브라우저 호환성**: 크로스 브라우저 지원
- **사용성**: UX 흐름, 인터랙션 피드백

## 검토 방식
1. 파일 읽기 및 구조 분석
2. 각 항목별로 발견사항 정리
3. 개선사항 보고 및 제안
4. **코드 수정은 사용자 승인 이후에만 진행**

## 중요 사항
- 검토 결과를 명확히 보고합니다
- 개선사항에 대한 구체적인 제안을 제시합니다
- 사용자가 승인하기 전까지 코드를 수정하지 않습니다
